# Megh Sanghani Portfolio

Static single-page portfolio prepared for GitHub and Vercel.

## Deploy

- Upload this repository to GitHub and import it into Vercel.
- Framework preset: Other
- Build command: leave empty
- Output directory: leave empty (project root)

The homepage is `index.html`. Five self-contained case-study pages are kept in
`case-studies/` and open in the same browser tab.

## Optional file

The hero currently references `Megh-Sanghani-CV.pdf`. Add the final PDF at the
project root to activate that download without changing the HTML.
